# Roadmap

## Phase 1 — Foundation (complete)

- central public catalog;
- separate installable skill repositories;
- GPL-3.0-or-later policy;
- machine-readable schema;
- local and CI validation;
- compatibility and contribution documentation.

## Phase 2 — Discovery and trust (current)

- searchable command-line catalog;
- remote repository verification;
- candidate admission audits;
- reusable repository scaffold;
- documented maturity model.

## Phase 3 — Catalog growth

- promote qualified public candidates through the documented admission process;
- add citation-validation, document-quality, research, and security-analysis skills as separate repositories;
- publish versioned catalog releases.
- advance the 20 approved concepts in [PROPOSED_SKILLS.md](PROPOSED_SKILLS.md) through repository creation, implementation, testing, and admission.

## Phase 4 — Ecosystem

- portable platform adapters;
- signed release artifacts and checksums;
- dependency and permission declarations;
- automated compatibility testing;
- curated community contribution process.
