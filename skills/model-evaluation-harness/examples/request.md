# Example request

Use this skill to handle the following realistic request:

> Compare a support-agent candidate with the baseline on accuracy, refusal, injection resistance, latency, and cost.

## Available evidence

- A versioned target or artifact identifier
- The applicable policy, expectation, or threshold
- Sanitized technical evidence appropriate to the scenario
- Named owners and an explicit authorization boundary

## Required result

Complete the report template, distinguish observation from inference, apply every acceptance check, and issue a decision without inventing missing evidence.
