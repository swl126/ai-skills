# Candidate Admission Process

Candidate reviews are intentionally repository-neutral until the underlying repository is public. Private repository names, contents, and audit findings are not published through this hub.

## Candidate gates

1. The repository is intentionally public.
2. Ownership and upstream provenance are documented.
3. Licensing is compatible with the catalog policy.
4. Platform-specific assumptions are isolated in adapters.
5. Required documentation, tests, and security guidance exist.
6. The default-branch workflow passes.
7. The public repository meets [STANDARD.md](STANDARD.md).

Useful is not the same as validated. A candidate enters `catalog.json` only after every gate passes.
